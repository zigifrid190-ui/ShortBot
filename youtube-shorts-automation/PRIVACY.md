# Privacy Policy

**Last Updated:** 2026-05-20

## 1. Introduction
ShortBot is a personal automation tool designed to create and publish content to YouTube and TikTok. This Privacy Policy outlines how the application handles data.

## 2. Data Collection
ShortBot is an automation script that runs locally on the user's machine. It **does not** collect, store, or transmit any personal data to third-party servers other than the platforms explicitly authorized by the user (YouTube and TikTok) for the sole purpose of uploading videos.

## 3. TikTok API Usage
ShortBot uses the TikTok Content Posting API. The application only accesses the permissions explicitly granted by the user (such as `video.upload` and `video.publish`) to push video files to the user's own TikTok profile.

## 4. Data Sharing
We do not share, sell, or distribute any user data. All authentication tokens (OAuth) are stored locally on the user's personal machine and are never transmitted to external databases.

## 5. Contact
As this is a personal, open-source automation tool, there is no formal support team. The code is available for review on GitHub.
